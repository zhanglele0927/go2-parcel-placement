# Go2 快递候选识别

用于巡检照片初筛，帮助复核人员快速定位疑似快递包裹。

## 输入和输出

输入单张照片，输出候选区域标注和检测摘要。本图来自本机插件运行。

## 如何解读结果

候选框是人工复核线索。遮挡、相似物和陌生场景可能导致漏检或误检。
